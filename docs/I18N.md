# WiseFoodies Internationalization (i18n) Architecture & Standards

WiseFoodies is a public-interest Indian food literacy and consumer guidance platform designed to empower citizens across all regions, languages, and writing systems of India.

This document details the architectural foundation, design principles, and technical implementation supporting **all 22 Scheduled Languages of the Eighth Schedule to the Constitution of India** plus English (23 locales in total).

## 2. Right-to-Left (RTL) Layout Support

Urdu (`ur`), Kashmiri (`ks`), and Sindhi (`sd`) use Perso-Arabic scripts and read right-to-left.

### Implementation:
1. **Dynamic Direction**: The `I18nProvider` sets `document.documentElement.dir = 'rtl'` when an RTL locale is active, and `'ltr'` otherwise.
2. **Immediate Pre-Hydration**: An inline script in `src/app/layout.tsx` inspects `localStorage` (`wf_locale`) or cookies on initial HTML delivery, setting `lang` and `dir="rtl"` before React mounts to prevent layout shifts.
3. **Selective LTR Exceptions**: Barcodes, raw numeric values, pricing (`₹`), email inputs, and code blocks retain `direction: ltr` through CSS utility `.force-ltr` to maintain mathematical readability.
4. **CSS Logical Properties**: Margin and padding use logical properties (`margin-inline-start`, `padding-inline-end`, etc.) or Tailwind CSS logical utilities so alignments mirror naturally.

## 4. Global Language Selector (`LanguageSelectorModal.tsx`)

Located in the global site header on desktop and mobile:
- **Instant Search**: Live search input filters by English name, native endonym, script name, or language code.
- **Visual Script Tags**: Every language badge displays its official script tag (`Devanagari`, `Bengali`, `Perso-Arabic`, `Ol Chiki`, etc.).
- **RTL Indicators**: Clear visual badges (`RTL`) for Urdu, Kashmiri, and Sindhi.
- **Accessibility**: Full keyboard support (`Escape` to close, arrow key focus trap, `aria-modal="true"`, `role="dialog"`).
- **Safe Persistence**: Stores user selection in `localStorage` (`wf_locale`) and cookie (`wf_locale=...; path=/; max-age=31536000`).
- **No Page Reload / State Loss**: Switching languages updates the React context dynamically without losing the active route, search query, or comparison selections.

## 5. Product Data Localization Layer (`lib/productLocalization.ts`)

### Preserving Factual Ground Truth:
Original product records (`data/products.json`) are the single immutable source of truth. Under no circumstance are factual nutritional quantities, ingredients, barcodes, or prices altered:
- `priceINR` remains unchanged
- `per100g` nutritional values (`proteinG`, `energyKcal`, `sodiumMg`, etc.) remain unchanged
- `packSizeG` and `servingSizeG` remain unchanged
- `fbs.score` and calculation breakdown formulas remain 100% identical

### Localized Presentation Fields:
`getLocalizedProduct(product, locale)` produces a presentation view containing:
- `localizedCategory`: Translated grocery category name across 23 languages (e.g., "Dairy & Frozen" -> "डेयरी और फ्रोजन" [hi], "দুগ্ধজাত ও হিমায়িত" [bn], "డైరీ మరియు ఘనీభవించినవి" [te]).
- `localizedVerificationStatus`: "Verified label" / "Incomplete label" in the target language.
- `localizedFBSBand`: "Good Choice", "Moderate", "Limited", "Ultra Processed / Avoid" in the target language.
- `localizedBenefits`: Translates standard nutritional claim templates while preserving exact quantities.
- `localizedConcerns`: Translates safety warnings (palm oil, high added sugar, refined flour) into clear, non-alarmist consumer explanations.

## 6. Food & Nutrition Glossary (`data/glossary/nutrition-glossary.json`)

To ensure scientific consistency and avoid misleading translations, 12 core food and nutrition concepts are formally defined with FSSAI-aligned definitions and verified across all 23 languages:
1. `protein` (Essential macronutrient for muscle repair and growth)
2. `totalSugars` (Sum of naturally occurring and added sugars)
3. `addedSugars` (Free sugars and syrups added during manufacturing)
4. `dietaryFibre` (Indigestible complex plant carbohydrates for gut health)
5. `sodium` (Electrolyte from salt and processing additives)
6. `saturatedFat` (Fats solid at room temperature linked to cardiovascular risk)
7. `ultraProcessed` (Industrial formulations with artificial additives and emulsifiers)
8. `wholeGrains` (Intact grain kernel retaining bran, germ, and endosperm)
9. `refinedFlour` (Stripped flour lacking bran and germ, e.g. Maida)
10. `servingSize` (Standardized portion quantified per consumption instance)
11. `fbsScore` (Algorithmic 0–10 score reflecting food nutritional quality)
12. `nutritionPerPaisa` (Quantitative ratio of protein/fibre delivered per rupee spent)

## 7. Multilingual AI Chatbot ("Ask WiseFoodies")

The AI Chatbot is built directly on the Gemini 2.5 Flash architecture with catalog grounding:
1. **Locale-Aware Prompting**: Injects the active website language and guidelines into the system instruction (`lib/ai/prompts.ts`).
2. **Two-Layer Scope Gate (`lib/ai/scope.ts`)**:
   - Rejects non-food queries (coding, politics, general science, creative writing) and dangerous medical diagnoses immediately.
   - Responds with **exact, culturally natural refusal sentences** in the user's selected language (e.g., Hindi: `"माफ़ कीजिए, मैं इसमें मदद नहीं कर सकता।"`).
3. **Deterministic Offline Fallback (`lib/ai/offlineFallback.ts`)**:
   - If the Gemini API is offline or unconfigured, the fallback handles product queries, brand comparisons, alternatives, and FBS score breakdowns in the selected language without crashing or showing raw errors.
4. **10 Grounded Tools (`lib/ai/tools.ts`)**:
   - `lookup_product`, `search_products`, `compare_products`, `find_healthier_alternatives`, `explain_fbs`, `nutrition_per_paisa`, `query_knowledge_base`, `analyze_basket`, `suggest_basket_swaps`, `get_category_rankings`.

## 8. Verification, Parity & Testing

### Running the Parity Check:
```bash
npm run i18n:check
```
Verifies that all 23 language files (`messages/{locale}.json`) possess **100% key parity** against `messages/en.json` (146 keys each).

### Running Unit & Comprehensive Tests:
```bash
npm test
```

- `test/i18n.test.ts`: Pure localization logic, formatting, and benefit/concern translation.
- `test/i18n-comprehensive.test.ts`: Complete 23-locale validation, RTL identification, Indian numbering formatting, product data localization, and exact refusal enforcement.
